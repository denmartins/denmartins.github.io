A disciplina de Programação Orientada a Objetos (5954018) apresenta os principais conceitos desse paradigma, utilizando Java como linguagem de programação. Ao longo do curso, os estudantes desenvolvem conhecimentos sobre classes, objetos, atributos, métodos, encapsulamento, herança, polimorfismo, agregações, coleções, programação genérica e reflexão. As aulas combinam fundamentos teóricos com atividades práticas em laboratório, promovendo a aplicação dos conceitos no desenvolvimento de software organizado, reutilizável e de fácil manutenção.

A disciplina é compartilhada com a [Profa. Thaína Tosta](https://dcm.ffclrp.usp.br/sobrenos-docente.php){:target="_blank" rel="noopener"}.
